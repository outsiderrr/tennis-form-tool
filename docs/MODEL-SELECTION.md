# APP 云端模型选型 · 调研与决策（2026-08-21）

数据来源：Artificial Analysis（AA，8 月中）、LMArena（8/19）、SuperCLUE 2026-07、Vectara HHEM（5/11，偏旧）、BenchLM（8/20）、各官方定价页。标「⚠︎」= 未能直接验证或来源单一。价格 = 每百万 token（输入/输出）。

## 基准指标速览（都测什么）

- **IFBench**：指令遵循（能不能严格按格式/约束输出）
- **Vectara HHEM**：摘要忠实度——给定材料后胡编的比例，越低越好（**和我们任务①最对口**，但榜单 5/11 更新，最新旗舰缺席）
- **AA-Omniscience 幻觉率**：不知道时会不会硬答（衡量「知之为知之」）。注意它和 HHEM measuring 的是两回事，多个模型两榜表现相反
- **LMArena 中文 Elo**：中文真人盲评偏好
- **AA 智能指数 / ARC-AGI-2 / GPQA**：推理硬度
- **SWE-bench Verified / WebDev Arena**：编码
- **MMMU-Pro / Video-MME**：视觉/视频
